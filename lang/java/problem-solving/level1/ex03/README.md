# ex03 - FtPutstr

| | |
|---|---|
| **Assignment name** | FtPutstr |
| **Expected files** | `FtPutstr.java` |
| **Allowed methods** | `System.out.print`, `System.out.println` |

---

## Instructions

Write a method that displays a string on the standard output.

Your method must be declared as follows:

public static void ftPutstr(String str)

---

## Compilation & Usage

​```bash
# Compile
mvn compile

# Run
java -cp level1/ex03/target/classes level1.ex03.FtPutstr "hello world"
​```
